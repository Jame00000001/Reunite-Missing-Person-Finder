# Reunite Frontend (Client)

The client application is built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Structure
- `/src/components/`: Reusable modular components (Navbar, Footer, ReportCard, SearchFilters, DetailsModal, PosterModal, etc.)
- `/src/pages/`: Pages for Home, Search, Report Missing, Report Found, User Dashboard, Admin Dashboard, Login, Register
- `/src/services/`: API client service for REST API communication
- `/src/context/`: Auth context managing JWT tokens and user state
- `/src/types/`: TypeScript definitions

## Start Frontend
```bash
npm run client
# Or
npm run dev
```
Runs at: `http://localhost:3000`
